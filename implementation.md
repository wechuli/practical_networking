# Course Improvement Implementation

Date: 2026-09-10. The original [review](improvements.md) records the pre-change
assessment. This file records implementation and verification, not a certification
that every environment or learner outcome has been tested.

## Implemented

- Replaced host-wide firewall, conntrack-exhaustion, port-exhaustion, and PMTUD
  demonstrations with namespace-owned fixtures, bounded operations, explicit
  assertions, process tracking, and cleanup.
- Added real DHCP, IPv6 RS/RA/ND/DAD/PTB, ARP conflict, two-VTEP VXLAN, protected
  WireGuard, bridge/VLAN/STP, and shaped performance exercises.
- Added tested local certificate-chain/mTLS/authorization, buffered sockets,
  DNS cache/fallback, concurrent HTTP/2, gRPC status/deadline/streaming, propagated
  traces, and structured synthetic flow-log exercises.
- Added explicit-context Kubernetes policy/Ingress/Linkerd fixtures, proxy
  header/failover checks, and separate learner/instructor capstone material with
  real DNS/TLS fault variants and an evidence-based rubric.
- Corrected protocol mechanisms, command/reference errors, unsupported certainty,
  version-sensitive behavior, and duplicated outline/summary claims across the
  course. Added NTP security, CONNECT, source-preservation/draining, and private
  service access guidance while retaining adequate existing explanations.
- Added [lab profiles](labs/README.md), pinned Python dependencies,
  [objective mapping](labs/index.md), and completed [appendices](appendices.md).

## Verification Record

socket framing/half-close/backpressure; certificate trust/served chain/mTLS;
resource authorization; DNS cache expiry/NODATA/TCP fallback; gRPC calls/status/
deadlines/streaming; actual concurrent HTTP/2 over one TLS socket; propagated
two-service spans; flow/metric assertions; seven DNS/TLS capstone fault repairs.

The final portable run passed dependency consistency (`pip check`), three socket
regressions, all TLS and authorization cases, all DNS cases, gRPC, HTTP/2, tracing,
flow analysis, and all seven capstone variants. The supplied gRPC proto also
compiled with protoc. Ten Kubernetes resource documents and the proxy Compose
configuration parsed successfully. Shell helper tests reject false-positive
"blocked" results from DNS/HTTP/missing-command errors and remove completed PIDs
from cleanup ownership. `git diff --check` passed and editor diagnostics were clear.

Static checks cover local document links, code fences, executable Python/shell
syntax, Kubernetes YAML parsing, and Docker Compose configuration. These are
not substitutes for packet-level execution on Linux or live controller schemas.
ShellCheck was not run: its optional Homebrew installation was declined and cancelled.
